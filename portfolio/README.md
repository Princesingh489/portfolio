# 🚀 Prince Kumar Singh - Premium Portfolio

This is a modern, high-performance portfolio website built with **React 19**, **Vite 8**, and **Tailwind CSS v4**.

---

## 🛠️ How to Run in VS Code (Step-by-Step)

Follow these steps to get the website running on your local machine:

### 1. Prerequisites
Make sure you have **Node.js** installed on your computer.
- Download it here: [nodejs.org](https://nodejs.org/) (Choose the **LTS** version).

### 2. Open the Project in VS Code
1. Open **VS Code**.
2. Go to `File > Open Folder...`.
3. Navigate to and select the `portfolio` folder:
   `C:\Users\Prince\Desktop\PortfolioWebsites\portfolio`

### 3. Open the Terminal
1. In VS Code, go to the top menu and select `Terminal > New Terminal`.
2. A small window will open at the bottom of VS Code.

### 4. Install Dependencies
In the terminal, type the following command and press **Enter**:
```bash
npm install
```
*This will download all the necessary libraries like React, Tailwind, and Framer Motion.*

### 5. Run the Development Server
Once the installation is finished, type this command and press **Enter**:
```bash
npm run dev
```

### 6. View Your Website
After running the command, you will see a link in the terminal like this:
`➜  Local:   http://localhost:5173/`

- **Ctrl + Click** the link, or open your browser and go to `http://localhost:5173/`.

## 📂 Project Structure
- `src/components/`: Contains all the sections (Hero, About, Projects, etc.).

- `public/profile.png`: Your profile photo.

- `npm run dev`: Starts the local development server.
- `npm run build`: Prepares the website for production (deployment).
